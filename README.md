# MDSM
MDSM (Mojang Don't Sue Me) is, at present, an attempt to recreate roughly the Minecraft Indev - Beta period of development, using mostly GPT-6.1 for code and for some assets, while other assets are partially or fully hand-drawn. Game has some quirks, but I try to do as much polishing and optimization as I can. 
## Future plans
Eventually, I intend to add new mobs, new gameplay mechanics, new ores, new dimensions, and so on. The ultimate goal is for the game to grow away from being a Minecraft clone and become more original/derivative.
