# MDSM

## About

MDSM (Mojang Don't Sue Me) is, at present, an attempt to recreate roughly the Minecraft Indev - Beta period of development, using mostly GPT-6.1 for code and for some assets, while other assets are partially or fully hand-drawn. As such, the game has some quirks and is generally imperfect. For example, there is no lighting system (ambient lighting only); hostile mobs spawn only in caves below a certain Y level, and there is no day-night cycle. Also, the game lacks infinite world generation, though this is more an intentional limit of scope. There may be random odd bugs as I have only performed basic playtesting and have not actually played through the full game naturally.

## Future plans

Eventually, I intend to add proper lighting, new mobs, infinite world generation, new gameplay mechanics, new ores, new dimensions, and so on. The ultimate goal is for the game to grow away from being a Minecraft clone and become more original/derivative. There is no telling how long this will take or if it will ever actually happen. So far, the only real addition I have made is adding obsidian armor/tools as a sort of stand-in for netherite.

## Technical details

While the game seems to mostly be functional, and I have tried to keep the architecture clean enough up to this point, it may well turn into a mess over time still. It is vibecoded slop at the end of the day. Bugs may increase in quantity and frequency over time, and things may just eventually get out of hand as the game grows in scope, to where I may need to abandon it.
