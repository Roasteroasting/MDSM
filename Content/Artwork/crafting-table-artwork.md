# Crafting Table artwork

Original textures were created with the built-in image-generation tool. No Minecraft assets were imported. The generated two-panel strip was sampled at pixel centers into two opaque 16x16 tiles, without interpolation, and pasted into previously unused terrain-atlas slots. All pixels outside these slots were compared against the original atlas and preserved exactly.

- Tile 16, row 1 / column 0: work surface (top and inventory icon).
- Tile 17, row 1 / column 1: cabinet/workbench sides.
- Bottom: existing plank tile 7.

The final editable asset is [terrain.png](../Blocks/terrain.png), built through its existing Content pipeline entry. No artwork is generated by the game or build.

Generation prompt:

> Create one game asset sprite strip for an original early voxel sandbox crafting workbench. A single horizontal strip of TWO square seamless tile textures, left TOP face, right SIDE face, equal size, edge to edge with no padding or separator or scene. Each tile represents EXACTLY a 16 by 16 logical pixel grid enlarged uniformly with nearest-neighbor crisp pixel blocks. Left: warm honey/oak wooden work surface with a dark brown border and an inset 3 by 3 scored working grid, modest wood grain. Right: wooden cabinet/workbench side, stout corner posts, a narrow drawer near upper edge, dark recessed lower panels and a couple subtle tiny tool/peg silhouettes. Flat orthographic texture maps, no perspective, no shadows outside pixel patterns, no text, no logos. Limited earthy brown palette, simple recognizable classic pixel-art, entirely opaque. Original artwork, do not copy Minecraft assets. The whole image is 2:1 aspect ratio. No extra objects or UI.
